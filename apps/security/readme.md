# Security Application.

- **App Key Manager:** Supports key encryption and decryption using the Storage Root Key (SRK).

- **eFuse Configuration Application:** Provides an eFuse Configuration Console to inspect device security settings, provision and verify the Secure Boot Public Key (SBK), and configure supported one-time programmable (OTP) eFuse security controls. The console is operated through a UART terminal.

The Security Application examples are divided into 2 categories.

-  **[App Key Manager](AppKeyMgr/readme.md)**

-  **[OTP efuse configuration](efuse_config_app/readme.md)**
