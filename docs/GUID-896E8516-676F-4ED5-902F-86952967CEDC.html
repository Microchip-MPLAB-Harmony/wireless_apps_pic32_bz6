6.3 Ethernet Peripheral

The net library, which is downloaded as part of Install Harmony 3 Dependencies, configures and generates code for the Ethernet peripheral. For more details, see Install Harmony 3 Dependencies from Related Links.

For more comprehensive documentation about the TCP/IP Stack Libraries Help, refer to the MPLAB® Harmony 3 TCP/IP Library in Reference Documentation from Related Links.

Additionally, the user can find the precompiled application examples in the <Harmony Content Path>\/net_apps_pic32cxbz6_wbz6 repository, providing users with ready-to-use examples to follow.

An application developer needs to connect a Microchip PHY daughter board to the Ethernet RMII headers (J909, J908, J906, J907). All application examples utilize the LAN8720 PHY Daughter Board. For more details, refer to the AC320004-3 LAN8720 PHY Daughter Board in Reference Documentation from Related Links.

The user can also find the Bluetooth Low energy transparent UART with TCPIP peripheral application example in wireless_apps_pic32_bz6/apps/ble/peripheral_applications/tcpip_tcp_server_trp_uart. For more details, see BLE + TCPIP_TCP Server Transparent UART from Related Links.
